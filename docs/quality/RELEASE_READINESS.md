# Prontidão de release

Exigir requisitos rastreados, P0/P1=0, checks e coverage verdes, scans aprovados ou exceção temporária aprovada e vigente, build de produção, smoke aplicável, backup/restore exercitado, instalação limpa do `setup.exe`, notas de limitação e CI remoto no SHA. Assinatura de código é requisito de release público, não deste bootstrap. Não declarar release pela validação local.
