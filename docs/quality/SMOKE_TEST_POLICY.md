# Política de smoke

O smoke final é de build de produção e cresce por entrega: iniciar, banco novo, configuração, conta, categoria, entrada, saída, transferência, produto, venda, recebimento, venda pendente, recebimento posterior, recorrência/pagamento, devolução, reembolso, confirmação de saldos, backup e restore controlado. Passos ainda não implementados são planejados, não executados.
