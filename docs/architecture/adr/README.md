# ADRs

- [ADR-028 — registro de saída pela interface](ADR-028-ui006-exit-form.md): comando Tauri create_exit e capability local mínima para UI-006.
- [ADR-029 — registro de transferência pela interface](ADR-029-ui007-transfer-form.md): comando Tauri create_transfer e capability local mínima para UI-007.
- [ADR-030 — cadastro de produto pela interface](ADR-030-ui008-product-form.md): contrato do comando create_product e capability local mínima para UI-008.
