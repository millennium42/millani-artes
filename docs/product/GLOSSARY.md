# Glossário

| Termo | Significado |
|---|---|
| Conta | lugar que possui saldo: dinheiro, banco/PIX, cartão ou outro |
| Contexto | classificação Casa ou Fábrica; não é uma conta |
| Movimento | entrada, saída ou transferência que altera saldo conforme o tipo |
| Venda | compromisso comercial com itens e valores congelados |
| Recebimento | dinheiro efetivamente recebido de uma venda |
| Reembolso | dinheiro efetivamente devolvido a cliente |
| Recorrência | obrigação mensal fixa ou variável |
| Produto | atalho reutilizável; não altera itens históricos |
| Backup | cópia criptografada do banco, validada antes de restaurar |
