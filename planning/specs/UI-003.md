# UI-003 — configuração inicial de contas

## Objetivo observável

Na janela local do Millani Artes, sem login, a pessoa pode cadastrar uma ou mais contas em um formulário acessível. A submissão chega ao caso de uso FIN-008 e grava conta e `audit_event` atomicamente no SQLite local. Saldo inicial permanece em centavos e não cria movimento nem receita.

## Decisões de apresentação

- Título “Configure suas contas”, com texto que informa que é possível cadastrar mais de uma.
- Formulário: nome da conta, tipo, saldo inicial; botão para salvar. Tipos e mapeamentos: Dinheiro (`cash`), Banco ou Pix (`bank_pix`), Cartão (`card`), Outro (`other`). Nenhum tipo vem pré-selecionado.
- O nome é enviado exatamente como digitado. Espaço em branco é rejeitado pelo caso de uso; a UI aponta o campo sem duplicar a regra.
- Saldo apresentado em reais com vírgula decimal: `-?[0-9]+(,[0-9]{1,2})?`, sem agrupamento de milhares. Zero casas representa reais inteiros; uma casa é completada em centavos; duas casas preservadas; mais casas, texto inválido ou valor fora de `i64` são rejeitados sem arredondar. Parser usa `BigInt`; IPC transmite centavos como string decimal canônica; Rust faz parse estrito para `i64`. Sinal negativo é admitido e não cria regra de negócio adicional.
- Sucesso anuncia “Conta criada. Você pode cadastrar outra.”, limpa o formulário e mantém a tela pronta para novo cadastro. Erro de nome é associado ao campo; falha de persistência recebe mensagem genérica, sem revelar path, SQL ou detalhes internos. Durante envio os controles ficam desabilitados e estado “Salvando…” é anunciado.
- Ordem natural de teclado: nome, tipo, saldo, salvar. Todos os controles têm rótulos visíveis; mensagens se ligam ao campo afetado e estado global usa regiões status/alert.
