# PLN-006 — Dependências canônicas do roadmap

## Objetivo observável

Cada microtarefa do roadmap declara predecessores explícitos ou independência, permitindo seleção mecânica da próxima tarefa desbloqueada.

## Critérios de aceite

- Blocos de desenvolvimento cobrem governança até release instalável.
- Todo ID é único; toda dependência aponta para ID existente e anterior.
- O documento separa RECON read-only de permissão de escrita.

## Evidência

Parse local verificou 242 tarefas, sem IDs duplicados, dependências ausentes ou dependências futuras. CI remoto não registrado.
