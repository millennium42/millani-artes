## Objetivo observável

## Contrato: entradas, saídas, invariantes, erros esperados
**Porta (Interface):**
```rust
trait AccountReadStore {
    type Error;
    fn read_all_accounts(&self) -> Result<Vec<Account>, Self::Error>;
}
```

**Caso de uso:**
```rust
fn list_accounts(store: &impl AccountReadStore) -> Result<Vec<Account>, ListAccountsError>
```

**Invariantes:**
- Leitura não deve modificar dados
- Erros são estáticos sem payload
- ID é convertido de BLOB para `[u8; 16]`
- `account_type` mapeia para: cash, bank_pix, card, other

**Erros esperados:**
- `ListAccountsError`: struct unit com `Debug`, `Display` e `Error::source` retornando `None`
- Erro genérico do store é mapeado sem expor detalhes
