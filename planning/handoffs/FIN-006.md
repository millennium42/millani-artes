```sql
    id BLOB NOT NULL PRIMARY KEY
        CHECK (typeof(id) = 'blob' AND length(id) = 16),
    name TEXT NOT NULL CHECK (name <> ''),
    account_type TEXT NOT NULL
        CHECK (account_type IN ('cash', 'bank_pix', 'card', 'other')),

```

A correção proposta `CHECK (name <> '')` com collation BINARY padrão rejeita somente vazio; mantém NUL e whitespace para a validação de domínio futura em FIN-008. Fonte: [SQLite core functions — length](https://www.sqlite.org/lang_corefunc.html#length). STRICT pode converter inputs compatíveis por afinidade; não alegar rejeição de toda forma coercível.
